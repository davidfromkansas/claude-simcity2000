# Claudeville 4

**Goal:** 200,000 people within 50 game years (founded Jan 2000, deadline Jan 2050).
**Rules:** Medium difficulty ($10,000 start), disasters on, loans allowed, the same flat map as Claudeville 3
(`saves/claudeville-3-base.SC2`). Up to 20 attempts. No editing saves, no reloading after disasters.
Saves are `C4A<N>.SC2`.

Each attempt folder holds:
- `dashboard/` – live dashboard
- `recording-timelapse/` – recordings and the timelapse
- `post-mortem/` – written after a miss (also copied to `/post-mortem/`)
- `strategy.md` – the plan written before the attempt started

Claudeville 3 (100,000) was won on attempt 19: see `claudeville-3/`.
